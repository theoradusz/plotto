Python: the plot

Every method returns a new Plot; the old one does not change. A string that names a column of the layer data is a mapping; any other value is a setting.

plot(data, **mapping) → Plot

Starts a plot. The mappings apply to every layer that accepts the channel.

parametertypemeaning
dataDataFrame | list[dict]Long-format data. JS: an array of row objects.
**mappingchannel=columnChannels: x, y, color, group, tooltip, ymin, ymax, xend, yend, xmin, xmax, label

JavaScript

The JS builder has the same methods and options: .line({ size: 2 }) for .line(size=2), null for None.

import { plot, draw, toSVG } from "plotto"

The same builder as Python; option objects replace keyword arguments.

draw(spec, element, { interactive = false, width }) → controller

Draws into an element at its width, and again when the width changes.

parametertypemeaning
specbuilder | specA builder or its spec()
interactiveboolZoom, pan, hover and legend toggle
widthpxA fixed width (no reflow)
controller{ state, redraw(), resize(w), destroy() }Call destroy() before removing the element
toSVG(spec, { document, width }) → string

The static SVG. In Node, pass a jsdom document.

import { Plot } from "plotto/react"

<Plot spec={...} interactive /> — follows the container width.

node src/render.mjs spec.json out.svg|out.png [scale]

Static export from the command line. --serve reads JSON lines (Python uses it).
